# Развёртывание

## Требования

- Python 3.10 или новее.
- Доступ сервера к Яндекс Календарю.
- Доступ экрана к серверу по сети.

## Запуск вручную

Из каталога проекта:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
mkdir -p data
YACAL_DATA="$PWD/data" .venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8080
```

Откройте `http://<адрес-сервера>:8080`, создайте учётную запись и подключите календарь.
Для подключения используйте пароль приложения Яндекса типа «Календарь».

## Сервис systemd

На Linux установите проект как сервис:

```bash
./deploy/install.sh
```

Сервис запускается автоматически и хранит данные в каталоге `data` проекта.
Проверить состояние и журнал:

```bash
systemctl status yacal
journalctl -u yacal -f
```

Установщик поддерживает `--no-service`, чтобы подготовить зависимости без создания сервиса.

## Экран

В настройках скопируйте адрес из поля «Адрес для монитора».
Откройте его в браузере на устройстве с экраном.

Для запуска Chromium на весь экран используйте скрипт:

```bash
./deploy/kiosk.sh "http://<адрес-сервера>:8080/d/<ключ>"
```

## Доступ из интернета

Для внешнего доступа разместите сервер за HTTPS reverse proxy.
Не публикуйте порт приложения напрямую в интернет.
После создания учётной записи отключите регистрацию через `YACAL_ALLOW_REGISTRATION=0`.
